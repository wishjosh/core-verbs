# Core Verbs

모바일에서 영어 문장을 통째로 입력하지 않고, 원어민이 자주 쓰는 표현 덩어리로 문장을 회상한 뒤 실제로 틀린 부분만 직접 체크하는 정적 웹앱입니다.

## 학습 흐름

1. 영어가 의미를 펼치는 순서대로 놓인 짧은 한국어 단서를 읽고 영어를 머릿속으로 떠올립니다.
2. 처음에는 짧은 조립 단위를 어순대로 고르고, 익숙해지면 문장에 따라 검수된 표현 청크 또는 더 긴 조립 단위로 연습합니다. 고른 단위는 빈칸 안에서 단어별 버튼으로 펼쳐집니다.
3. 펼쳐진 단어 중 실제로 다르게 생각하거나 말한 단어를 다시 누릅니다. 이어진 여러 단어를 누르면 청크 경계를 넘어도 하나의 구문 오류로 묶입니다. 정답에 없는 말을 덧붙였다면 `정답에 없는 말을 더했어요`에서 그 말과 들어간 위치만 기록합니다.
4. 조립을 확인하면 자연스러운 한국어 뜻과 올바른 영어 청크 어순이 나타납니다.
5. 앱은 문법 유형을 미리 단정하지 않고, 선택한 실제 단어 위치와 이어진 구간, 자동 감지한 청크 어순 오류와 문장 전체 회상 실패 여부를 문장과 함께 기록합니다.
6. `모두 맞았어요` 또는 `선택한 오류 저장`으로 자기 채점을 마치면 결과가 복습 일정에 반영됩니다. 오답 원자료는 최근 100건까지만 별도로 보관하며 설정에서 JSON 파일로 내보낸 뒤 외부 AI에 직접 첨부해 반복 패턴을 분석할 수 있습니다.

새 문장은 하루 최대 12개입니다. 복습량과 최근 회상 정확도에 따라 실제 하루 한도는 12개, 8개, 4개 또는 0개로 조절되며, 새로고침해도 그 한도를 넘겨 새 문장을 배정하지 않습니다. 정상 학습일에는 HAVE·GET·MAKE·TAKE를 각각 3개씩, 부담을 줄인 날에는 각각 2개 또는 1개씩 배정합니다. 먼저 끝난 핵심 동사의 빈자리는 나머지 동사 문장으로 채우며, 네 동사가 모두 끝나면 전체 나머지 문장에서 무작위로 배정합니다. 한 세션은 새 문장과 복습을 합쳐 최대 20개입니다.

오늘 배정된 학습이 끝나거나 새 문장 한도를 이미 채운 상태라면 완료 화면에서 선택할 수 있습니다. `복습 10문장 더 하기`는 이미 배운 문장 중 오답 누적이 많고 복습 간격이 짧은 문장을 우선 사용하며, 맞은 문장의 기존 복습 예정일을 억지로 뒤로 미루지 않습니다. `진도 없이 체험하기`는 최대 10문장을 연습하되 문장 진도, 오류 기록, 복습 일정에 결과를 전혀 저장하지 않습니다.

같은 기기와 브라우저에서는 학습 기록이 자동으로 이어집니다. 완전히 새로 시작하려면 설정의 `학습 진도만 초기화`를 사용합니다. 두 번 확인한 뒤 문장 진도·복습 일정·오늘 학습량·오류 기록만 삭제하며, 질문 노트와 음성 설정은 유지합니다. 삭제한 진도를 되돌려야 한다면 초기화 전에 백업 파일을 만들어야 합니다.

청크 난이도는 869문장 전체에서 문장별로 자동 조절됩니다. 전 문장에 저장된 의미 청크와 영어 어순 한국어 단서를 첫 단계로 사용하고, 숙달되면 강한 문장부호를 넘지 않는 범위에서 인접 의미 단위를 더 길게 묶은 뒤 선택지 없는 전체 회상으로 넘어갑니다. 같은 단계에서 힌트 없이 두 번 연속 맞으면 다음 단계로 올라가고, 실제 단어 오류·추가 단어 오류·자동 감지한 어순 오류 또는 전체 문장 실패가 있으면 한 단계 내려갑니다. `정답 바로 보기`만 사용한 경우에는 현재 단계를 유지하며, 짧은 관용 표현이나 선택지가 하나뿐인 중복 단계는 자동으로 생략합니다.

`MAKE` 단원의 100문장은 `data/make-chunk-overrides.json`에서 한 단계 더 세분화해 직접 검수합니다. 각 문장에는 첫 학습용 `microChunks`·`microOrderGlosses`와 숙달 뒤 사용할 `assemblyChunks`·`orderGlosses`가 함께 들어 있습니다. 나머지 문장도 이미 문장별로 분석해 저장한 의미 청크를 세부 단계로 사용하므로 실행할 때 영어만 기계적으로 다시 쪼개지 않습니다. 짧은 단계에서도 관사+명사, 부정·조동사+동사, 구동사처럼 함께 익혀야 하는 결합은 임의로 끊지 않습니다. 영어 원문은 모든 단계에서 글자와 문장부호까지 동일하게 복원되어야 합니다.

오류 기록 파일은 정답에서 선택한 단어 위치뿐 아니라 정답에 없던 말의 `insertedText`, 앞뒤 정답 단어 위치와 문맥도 저장합니다. 예를 들어 `Have you ever seen ...?`이라고 떠올렸다면 `Have`나 `you`를 틀렸다고 표시하지 않고, `ever`가 `you` 뒤·`seen` 앞에 추가되었다고 기록합니다. 문법 유형은 앱이 미리 붙이지 않으며, 내보낸 최근 100건을 AI가 문장 문맥과 함께 분석하도록 둡니다.

## 저장된 문장 자료

`data/learning-content.json`에 50일, 869문장의 학습 자료를 저장합니다. 앱은 이 파일을 우선 사용하므로 배포 후에도 매번 청크를 기계적으로 다시 만들지 않습니다. 각 항목에는 다음 정보가 들어 있습니다.

출처의 영어 문장은 수정하지 않습니다. 학습 청크는 보통 1~4단어로 나누고, 자연스러운 결합 표현에 필요한 경우에만 5단어까지 허용합니다. 모든 청크를 다시 연결했을 때 원문과 글자·문장부호까지 정확히 같도록 검사합니다.

- `assemblyChunks`: 원어민 청크 단위의 영어 정답 경계
- `orderGlosses`: 영어가 앞에서부터 펼치는 의미·기능을 청크별로 보여 주는 한국어 단서
- `microChunks`, `microOrderGlosses`: 직접 검수한 단원에서 첫 학습에 사용하는 더 세밀한 의미 단위와 1:1 한국어 단서
- `naturalKo`: 정답에서 보여 주는 자연스러운 한국어 뜻
- `corePatterns`: 문제 생성과 콘텐츠 검수에 쓰는 내부 구문 메타데이터(별도 핵심 구문 상자로 노출하지 않음)
- `errorPoints`: 학습 선택지와 콘텐츠 검수에 쓰는 내부 혼동 포인트 메타데이터(학습 화면에서 오류 유형 선택으로 노출하지 않음)
- `reviewStatus`: 영어 청크 자료의 초안·검수 상태
- `meaningFlow`: 의미 전개 규칙 버전과 별도 검수 상태(`reviewed` 또는 `ai_checked`)

869문장 모두에 의미 전개 규칙 1을 적용했습니다. 대표 30문장은 직접 검수한 `reviewed`, 나머지 839문장은 Codex가 문장별로 작성한 뒤 고위험 표현과 표본을 다시 확인한 `ai_checked`로 구분합니다. 원본 Google Sheets는 자료를 다시 만들 때의 입력과 이전 배포본의 예비 경로로만 사용합니다. `scripts/generate-learning-content.mjs`는 원문 보존, 청크 재조립, 문장부호 경계, 의미 전개 단서의 1:1 대응과 오류 선택지의 유효성을 검사합니다.

## 실행과 검사

빌드 과정이 없는 HTML/CSS/JavaScript 앱입니다. `localhost`에서 실행해야 PWA와 서비스 워커를 확인할 수 있습니다.

사람이 직접 검수한 30문장만 연속으로 확인하려면 `http://localhost:8000/?pilot=meaning-flow`로 접속합니다. 일반 주소에서는 869문장 전체와 기존 학습 일정이 적용됩니다.

직접 검수한 `MAKE` 단원 100문장만 확인하려면 `http://localhost:8000/?verb=make`로 접속합니다. 별도 화면이나 설정 버튼을 추가하지 않고 기존 학습 흐름과 같은 방식으로 세부 청크부터 시작합니다.

```powershell
python -m http.server 8000
node --test learning-engine.test.js learning-content.test.js scripts/audit-meaning-flow.test.mjs
node --check app.js
```

문장 자료를 다시 만들 때는 로컬 Ollama 모델을 실행한 뒤 다음 명령을 사용합니다. 중간 결과는 캐시에 저장되어 중단 후에도 이어집니다.

```powershell
node scripts/generate-learning-content.mjs --mode=generate --model=gemma4:e4b --batch=10
node scripts/generate-learning-content.mjs --mode=quality --model=gemma4:26b --batch=8
node scripts/generate-learning-content.mjs --mode=validate
node scripts/apply-meaning-flow-batches.mjs --validate-only
node scripts/audit-meaning-flow.mjs --batches=data/meaning-flow-batches
node scripts/apply-meaning-flow-batches.mjs
```

첫 번째 단계가 869문장의 청크 초안을 만들고, 두 번째 단계는 한정사·접속사·전치사 경계와 임시 번역처럼 명백한 문제만 더 큰 모델로 다시 심사합니다. 확정한 의미 전개 문구는 9개 배치 원본에 저장하며, 적용 도구는 사람 검수 30문장을 우선 보존한 채 나머지 839문장만 병합합니다.

각 배치에는 `id`, 영어 원문, 고정 청크, 한국어 의미 전개 단서를 함께 저장합니다. 적용 전후에 영어 원문과 `assemblyChunks`를 다시 비교하며, 누락·중복·1:1 불일치가 하나라도 있으면 `data/learning-content.json`을 쓰지 않습니다. 감사 도구는 부정, `only to`, 사역·수동, 기본동사 다의어, 관용구와 고위험 문장 86개를 별도로 검사합니다.
